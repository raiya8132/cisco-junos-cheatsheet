Junosに慣れていない人が最初につまずく点

  • 設定は commit するまで反映されません。copy run start に当たる操作も commit です。
  • 設定前後の差分は show | compare、元に戻すのは rollback 1 です。
  • リモート作業では commit confirmed 5 を使うと、5分以内に確認の commit がなければ自動で戻ります。
  • Junosの ping は止めるまで送り続けます。count 5 を付けるのが無難です。
  • 設定を行単位で見たいときは show configuration | display set が便利です。

注意：機種（EX／QFX／MX／SRX）とJunosのバージョンで構文が異なる場合があります。特にスイッチのVLAN設定は、ELS対応機種と旧構文の機種で書き方が違います。本番環境に投入する前に、必ず実機で確認してください。
